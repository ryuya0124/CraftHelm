# 画面とサーバーデータ（v0.1.13）

左側のサーバーを選び、主メニューから概要・コンソール・バックアップ・サーバー設定を選びます。「サーバー設定」の画面内左メニューには種類とバージョン、Java/メモリ/ポート、起動引数、本体導入、ゲーム設定とMOD・プラグインの一覧、検索、プリセット、MODパック、AutoModpack、設定編集があります。各項目の内容は右側に表示します。サーバー名を右クリックすると設定または削除画面を開けます。

画面左下の「アプリ設定」には専用のホームがあります。画面内左メニューから表示、更新、Javaの管理、PC情報、接続診断、ガイドを選べます。アプリ設定はサーバーの選択と無関係に開けます。

サーバー設定とアプリ設定では、左の項目一覧と右の内容を別々にスクロールできます。長いMOD設定フォームを下へ送っても項目一覧は動きません。同じ設定画面内で項目を切り替えたときは、左のスクロール位置を保持し、右の内容を先頭から表示します。サーバー名の右クリックメニューもアプリの表示テーマに合わせています。

## サーバーの削除と一覧

「サーバーを削除」で選択中のサーバーの名前と実際の保存先を確認できます。稼働中は削除できません。「一覧からのみ削除」は登録だけを消し、ファイルを残します。「サーバーフォルダもゴミ箱へ移動」はそのサーバーのフォルダをWindowsのゴミ箱に送って登録を消します。バックアップとログは残ります。ゴミ箱に移せない場合に永久削除へ切り替えることはありません。

サーバーフォルダが外部操作でなくなった場合、起動時と起動中約5秒ごとに一覧から登録を外します。稼働中のサーバーは対象外です。外れた登録のバックアップとログは残ります。フォルダを削除する前にワールドが必要か確認してください。

## バックアップ

停止中のサーバーをZIPへ保存します。既定の高速方式は無圧縮で、既に圧縮されたJARや大量のデータを速く保存できます。保存先には元データに近い空き容量が必要です。圧縮方式は容量を節約できますが、CPU使用量により遅くなることがあります。進捗はファイル数・読み取り済みMB・概算MB/sを表示します。キャンセル時は未完成の`.partial`ファイルを削除します。保存先を開く操作はバックアップ中も使えます。

速度はCPU、SSD、キャッシュ、ファイル構成、同時実行中の処理で変わります。2026-09-23のこのPCで192MiBの乱数データ1ファイルを使った短時間測定では、従来方式に相当するFastest圧縮が123.5MiB/s、高速方式が2560.4MiB/sでした。これはOSのファイルキャッシュを含む値で、長時間のディスク実効速度を保証しません。

## テスト環境

今回の実サーバーテストはDocuments内の専用の新規フォルダを使用し、127.0.0.1:56710でVanilla 1.21.1を起動しました。指定された`minecraft\_server2 (コピー)`は使用していません。既存のJavaプロセスは継続し、テスト用のプロセスだけを通常停止しました。結果JSONを保存した後、今回作ったテスト用サーバー・クライアント依存パッケージ・速度測定データをWindowsのゴミ箱へ移しました。
