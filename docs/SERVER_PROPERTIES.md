# サーバー設定GUI

左側でサーバーを選び「サーバー設定」を開きます。既存のserver.propertiesにある項目を表示し、名前・キーで検索できます。真偽値はチェック、難易度やゲームモードは選択、数値は範囲を確認して保存します。パスワード・secretを含むキーはマスクします。

難易度の旧数値は0＝ピースフル、1＝イージー、2＝ノーマル、3＝ハードです。初期ゲームモードは0＝サバイバル、1＝クリエイティブ、2＝アドベンチャー、3＝スペクテイターです。画面には日本語名で表示し、変更しなければ既存ファイルの数値表記を保持します。別の選択肢へ変更した場合は名前形式で保存します。

停止中に「サーバー設定を保存」を押してください。日本語はJava propertiesのUnicodeエスケープで保存し、再表示時に戻します。未変更のコメント・未知の項目・並び順を保持します。保存前の内容は設定履歴へ残ります。別のエディターで変更されていた場合は保存を拒否するため、画面を開き直して変更を確認してください。

server-portを変更すると起動設定のポートも同期します。起動時のポートは起動設定が優先されるため、既存ファイルと異なる場合は画面の注意を確認してください。ファイルがない場合は基本項目だけを用意し、保存するまでは作成しません。バージョンによって存在しない項目を無条件に追加しません。

通常は次回起動から反映されます。既存ワールドの生成条件は再生成されず、実装やバージョンによってゲーム内設定が優先される項目もあります。GUIにない項目の追加は「ファイル・設定」のテキスト編集を利用できます。RCON項目は設定できても、RCON接続クライアント機能はありません。
