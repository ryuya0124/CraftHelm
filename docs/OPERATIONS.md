# 運用・復旧

## 保存構造

```text
Documents/CraftHarbor/data/
  profiles.json              起動プロファイル
  servers/<id>/              サーバー・ワールド
  backups/<id>/*.zip          サーバー全体のバックアップ
  presets/<id>/*.zip          MOD・plugins・configの構成
  java/                      アプリ専用Java
  logs/<id>/*.log             実行ごとのコンソールログ
  file-history/<id>/          設定保存前の旧ファイル
```

バックアップZIPには `servers/<id>` の内容が入り、`profiles.json` やJavaは含まれません。PC移行ではアプリを閉じてdataフォルダ全体をコピーし、保存されたJavaの絶対パスを更新してください。DocumentsがOneDrive同期対象の場合、稼働中のワールドと同期の競合に注意し、必要なら `CRAFTHARBOR_DATA` を非同期フォルダに指定してください。

## バックアップと復元

1. 対象サーバーを通常停止します。
2. バックアップ画面で「高速（圧縮なし・容量大）」または「圧縮（容量を節約）」を選び、ZIPを作ります。進捗と実測速度を表示し、途中でキャンセルできます。保存先は処理中も開けます。
3. 復元するZIPを選び、確認すると別フォルダへ展開・検証します。
4. 完了したデータへフォルダを切り替えます。直前のデータは `.previous-*` に残ります。

ZIP破損・パス不正時は元サーバーを変更しません。展開上限は20GB、10万エントリです。大規模ワールドはこの上限を超えるため本版の復元対象外です。バックアップ作成には上限を設けていないので、20GBを超える展開サイズのZIPは外部の検証済みツールで復元してください。自動世代削除はありません。ZIPと.previousの分の空き容量を確保してください。

復元しても起動設定は変わりません。昔のワールドを使う時はMC・MOD・Javaの設定も合わせてください。ダウングレードはワールドを壊す場合があるため、元データを残して確認します。

## 既存サーバーの取り込み

取り込みはコピーのみで、元フォルダを書き換えません。ただし動いているワールドのコピーは一貫しません。元サーバーを停止できる時に行ってください。既存Javaプロセスを探索して停止する機能はありません。

Forge / NeoForgeは事前にローダーを導入したサーバーフォルダをコピーします。カスタム引数に、配布元のrun.batにある `@libraries/.../win_args.txt` と `nogui` を別行で入力してください。`user_jvm_args.txt` が必要ならその参照も別行に追加します。BATをCraftHelmから実行する機能はありません。

## ネットワーク

システム画面はLAN IPとローカルのTCP待受を表示します。TCP疎通チェックは4秒でタイムアウトします。成功はそのホストへのTCP接続だけを意味し、Minecraftのログイン・MOD整合性や外部からの到達性は保証しません。

外部公開にはWindows FirewallでのJava/TCPポート許可と、ルーターの同ポート転送が一般に必要です。CGNATなど環境によっては単純な転送では公開できません。アプリはFirewall・ルーターを自動変更せず、外部IPを第三者APIへ問い合わせません。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| アプリが起動しない | portableは.NET 10 Desktop Runtime x64。standaloneを試す |
| Javaが見つからない | Java画面で導入・割当。javaw.exeではなくjava.exe |
| UnsupportedClassVersionError | サーバーとMODが必要とするJavaの世代 |
| ポート使用中 | 今動いているサーバーを維持したまま、新規側のポートを変更 |
| サーバーが落ちる | logsとcrash-reports、MC / ローダー / MODの組み合わせ |
| MODが二重に入る | 古いJARを無効化して新しい版と1つだけ有効にする |
| 停止がタイムアウト | 大きいワールド保存を待つ。強制終了は最終手段 |
| ダウンロードできない | ネット接続、配布API、安定版の有無。勝手に別版には切り替わらない |
| profiles.json破損 | ファイルを退避してバックアップから復元。アプリは空データで上書きしない |
| ディスク不足 | logs / backups / .previous-* の不要データを停止中に整理 |

OSの強制再起動やタスクマネージャーでのアプリ強制終了には対応できません。CraftHelmを再起動しても既存プロセスへ再接続しません。再起動後の稼働プロセスは元の方法で適切に停止してください。
