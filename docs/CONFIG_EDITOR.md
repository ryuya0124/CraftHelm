# 設定ファイルのテキスト編集

サーバー設定 → テキスト編集を開きます。ファイル名・フォルダ名を検索するか、基本・MOD設定・プラグイン・ワールド・スクリプト・AutoModpackで絞り込みます。「最近」は更新日時が新しい25件を表示します。左の一覧にはファイル名と保存フォルダを表示し、右の編集欄で内容を変更します。「一覧を更新」で外部で追加された設定を読み直せます。

JSON・JSON5・JSONC・TOMLはキー、文字列、数値、コメントなどを色分けします。properties・YAML・CFG・SNBTなどの設定形式とJS・ZSスクリプトも基本的な色分けに対応します。行番号を表示し、ライト・ダークの両テーマに合わせます。色分けは入力内容を解釈して保存する機能ではありません。テキストを自動整形せず、そのまま保存します。従来どおりJSONのみ構文を検証し、その他の形式の妥当性は対応するMOD・プラグイン側で確認してください。

未保存のまま別ファイルへ切り替えると確認画面を表示します。検索・分類の切り替えだけでは編集中の内容を捨てません。保存は停止中のサーバーで行い、保存前の原本は`file-history`に残します。画面表示は最大500件、1ファイル1MB未満で、プリセットやバックアップの対象範囲は変わりません。

色分け・行番号には[AvalonEdit 6.3.1.120](https://www.nuget.org/packages/AvalonEdit/6.3.1.120)を使用します。MITライセンスの全文は配布物の`licenses/AvalonEdit-LICENSE.txt`に同梱しています。
