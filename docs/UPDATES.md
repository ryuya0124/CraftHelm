# アプリの自動更新

v0.1.8以降のインストーラー版では、初期表示の後と24時間ごとにGitHub Releasesを確認します。開発途中のプレビュー版も更新対象です。「アプリの更新」で無効化・手動確認・準備済み更新の適用と再起動ができます。ZIP版は確認のみで、自動適用しません。

新しい版のsetup.exeとSHA256SUMS.txtが両方公開されている場合に取得します。サイズとSHA256を照合し、通常のアプリ終了後に別プロセスで再照合してインストールします。常駐サービスは追加しません。GitHubの公開リポジトリなのでログインは不要です。非公開状態の開発環境では既存のGitHub CLI認証にフォールバックできます。

「更新してアプリを再起動」は新しい版のインストーラーをダウンロード・検証し終えた場合だけ表示します。押すと確認画面を表示します。CraftHelmから起動したサーバーが稼働している場合は対象名を表示し、ユーザーが了承したときだけ通常のstopコマンドで安全に停止します。停止に失敗した場合は更新・再起動を行いません。通常のアプリ終了では稼働中・処理中のサーバーがあると終了と更新を拒否します。更新処理は親アプリの終了を最大2分待ち、強制終了しません。Minecraftサーバーは更新後に自動起動しません。

設定はデータ領域のupdates-preferences.json、取得物・結果・インストーラーログは %LOCALAPPDATA%\CraftHarbor\updates に保存します。更新によってDocuments内のワールド・MOD・設定を削除しません。取得失敗や検証エラーは更新画面へ表示し、後で再試行できます。終了後の適用結果はapply-*.json.result.json、詳細は*.install.logで確認できます。適用に失敗した場合はGitHub Releasesから手動インストールできます。

SHA256は取得物の整合性確認です。Windowsのコード署名や、GitHubアカウントの侵害に対する保証ではありません。自動更新が無効な場合、取得済み更新も通常終了だけでは適用しません。
